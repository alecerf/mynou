# Proposed Mynou 0.22.15 — Owner-bound private PAR2 recovery persistence

Add a safe Rust std-only recovery workspace library API using captured Usenet
owners, standard file locking and existing checked private frames. Reconstruct
and verify every file before creating a new private namespace. Synchronize the
File-ID-named outputs and publish one bounded descriptor with exact owner/source,
Main-order inventory and immutable resource policy. Reopening verifies the
complete directory, descriptor, SHA and original slice/full/prefix integrity.

Original inputs and existing directories/files are never repaired or overwritten.
The supported Unix filesystem must have a caller-controlled private parent;
links, nonprivate modes, unknown/missing/corrupt inventory and detected identity
changes fail closed. Cancellation is cooperative; incomplete staging remains
unpublished and is not adopted. A post-rename durability error requires checked
reopening, not a success claim. No hostile atomic snapshot is promised.

This is a persistence prerequisite, not automatic Usenet repair or library
admission. Current requester/job/destination approval, acquisition, native media,
import and Plex gates remain mandatory for later integration. Six original
CI-only fixtures challenge persistence/reopen, locking, owner/source/policy/schema,
rehashed corruption, inventory, bounds/cancellation, links and private modes.
The prior 858-test baseline must remain green. Separate complete-diff Security
and independent logical QA precede objective-gated merge and immutable Actions
publication. [Issue #15](https://github.com/alecerf/mynou/issues/15) retains live state.
