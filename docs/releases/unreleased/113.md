## Usenet, PAR2 and archive processing removed

Mynou now acquires media through torrents only. Usenet downloads, Newznab indexers, NNTP providers, PAR2 repair and ZIP/RAR extraction are gone, with their commands, API routes and browser page. Before upgrading, remove the `usenet` section and every `newznab` indexer from `mynou.json`; Mynou refuses to start with them and says what to change.

Requests started through Usenet are halted and never resumed, and their imported files stay in your library. With Mynou stopped, run `mynou retire-usenet` to review them, then apply the plan it prints. This removes the indexer links, which may contain your API key, from the job journal. Older Mynou versions can no longer open the journal after that. Rotate your indexer API key if you are concerned, and delete the Usenet state directory yourself once you no longer need it. See [Usenet removal](../../usenet.md).
