## Usenet, PAR2 and archive processing removed

Mynou now acquires media through torrents only. Usenet downloads, Newznab indexers, NNTP providers, PAR2 inspection and repair, and ZIP/RAR inspection and extraction are removed, along with their commands, API routes and browser page.

Mynou rejects configuration fields it no longer knows. Before upgrading, delete the `usenet` section and every indexer whose `kind` is `newznab` from `mynou.json`.
