## Optional live progress

Following Jobs or Transfers no longer requires repeatedly refreshing the page.
Lists and details offer Enable live updates, Pause updates and Refresh page.
The enhancement starts paused and changes only the displayed state, progress,
attempts and byte/seeding counters. Filters, pagination, selected rows, keyboard
focus and unfinished forms remain in place.

Requests run only while enabled and visible, every ten seconds with one in flight
and an eight-second deadline. At most 50 displayed identifiers and 48 KiB per
reply are accepted. Whole replies are validated before updates; aborted or stale
responses cannot change the page. Missing entries stay visible as Unavailable.
Authentication failure stops updates and offers sign-in; other failures pause
until explicit retry. Freshness is the time of the last accepted response.

The native read-only projection looks up only selected torrent identities, without
building file lists, policy snapshots or request references. Unsigned 64-bit
counters remain exact decimal strings. Browser sessions remain distinct from API
Bearer authentication; exact origin, no-store, nosniff and anti-framing guards
remain required. Replies omit private metadata, credentials and diagnostics,
leave flash messages intact and do not renew sessions or acquire content.

One original embedded first-party script uses exact SHA-256 CSP/SRI content
pinning. No inline scripts, handlers, evaluation, third-party code, npm packages
or product runtime helpers are added. Manual refresh and native forms remain
available without the enhancement. Real-browser and assistive-technology
interoperability are not independently verified.

Original CI-only HTTP/session/query/privacy/read-only scenarios and Node
standard-library behavior fixtures cover opt-in, single-flight deadlines,
visibility and pause races, stale/oversized/invalid replies, authentication,
exact counters and preserved edited controls. No local checks are claimed.
