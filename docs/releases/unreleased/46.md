## Upgrade owned movies and episodes through Usenet

`mynou upgrades` can replace an ordinary owned movie or episode with a better release from a configured Newznab source when native Usenet downloads are enabled. Preview never downloads; apply records one pending replacement that keeps the old import until the new file is verified and imported beside it (and confirmed in Plex when enabled). Scheduled monitoring queues these upgrades like torrent upgrades, and a failed one can be followed by a different top candidate. Shared groups, packs, IRC and archive or PAR2 releases are not upgraded this way. Once an upgrade is recorded, older Mynou versions cannot open the store. See [Usenet](../../usenet.md#usenet-upgrades).
