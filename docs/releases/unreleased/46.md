## Upgrade owned movies and episodes through Usenet

`mynou upgrades` can replace an ordinary owned movie or episode with a better release found through a configured Newznab source when native Usenet downloads are enabled. Preview never downloads; apply records one pending replacement that keeps the old import until the new file is verified, imported beside it and confirmed in Plex. Shared groups, packs, IRC and archive or PAR2 releases are not upgraded this way. See [Usenet](../../usenet.md#usenet-upgrades).
