# Unreleased notes

Each user-visible change merged since the latest release adds one file here,
named after its Issue: `<issue>.md`. Write for people who run Mynou:

```markdown
## Short user-facing title

One to three sentences: what changed for users, how to use it and any limit.
See [the relevant guide](../../web.md) when one exists.
```

Do not record CI runs, review evidence or engineering process here. A release PR
merges these files into `docs/releases/<version>.md` and deletes them, keeping
this README.
