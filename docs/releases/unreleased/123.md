## Container assembled from Actions inputs

GitHub Actions now builds the container `FROM scratch` from the checked static
executable and the GitHub-hosted runner's CA bundle, so packaging no longer
pulls a Rust/Alpine image from Docker Hub. The image trusts whatever
`ubuntu-latest` ships on the build date, so rebuilds are not reproducible; the
job logs the bundle's SHA-256, and `MYNOU_CA_FILE` still overrides it.

Docker no longer compiles the sources. A local image build needs the musl
release binary and a PEM CA bundle in `.ci-image/`; the
[Docker guide](../../deployment.md#build-the-image-locally) lists the steps.
