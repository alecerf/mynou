## Container assembled from Actions inputs

GitHub Actions now assembles the container directly from `scratch`, using the
checked static executable and the GitHub-hosted Linux runner's CA bundle.
Packaging no longer pulls a Rust/Alpine image from Docker Hub. The CA bundle
follows runner updates and is checked against the file copied into the image;
custom trust bundles still use `MYNOU_CA_FILE`.

Local image builds now require a prepared Linux-musl executable and PEM CA
bundle in `.ci-image/`; Docker no longer compiles the sources.
