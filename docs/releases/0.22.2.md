# Mynou 0.22.2 — Checked Usenet receipts and streamed file recovery

New private single-file workspaces bind exact NZB, file index, provider and size
limits. Verified yEnc parts retain expected article identity in bounded checked
frames. Immutable receipts are idempotent, revalidated at restart and never
replaced on conflict. Private directories/files, owner locks, format/length/SHA
checks and link rejection fail closed before reuse.

Streamed assembly reads one bounded part and writes 64 KiB chunks while requiring
exact coverage and complete CRC. Output may exceed the in-memory 64 MiB cap within
the captured file limit. Prepared SHA/CRC/length proofs precede atomic publication
and ready state; restart verifies/reconciles that boundary without reacquisition.
Offline recovery writes nothing and foreign outputs are preserved.

Original local fixtures cover corruption, bindings, ownership, coverage, CRC,
private/link checks, publication windows and a 65 MiB output. This source needs
its own complete Actions run. Rust std only, zero dependencies and CI-only
publication remain mandatory. Background queue/controls, ordinary Engine admission
and Newznab follow; archive extraction and PAR2 repair are not implemented here.
