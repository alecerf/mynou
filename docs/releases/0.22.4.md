# Mynou 0.22.4 — Typed native Newznab discovery

Newznab sources now advertise explicitly typed Usenet candidates. Ordinary title,
year, episode numbering and selection profiles remain required. Configured size
intervals and password flags reject unsuitable advertisements; torrent seed
thresholds do not apply to Usenet. Public previews retain opaque candidate IDs
and safe transport/size/decision fields while withholding download references.

Captured targets bind an immutable native indexer policy and NNTP provider.
Library callers can read a bound original NZB document using the existing native
authentication, pause/generation fences, rate limits, same-origin policy, body
limits and absolute deadline. Strict NZB parsing still precedes use. Neither
discovery nor document reads acquire articles, enqueue work or admit library jobs.
Automatic library admission follows in a separate increment. Ordinary torrent
selection explicitly rejects NZB results, and torrent source binding bytes remain
compatible with the preceding checked policy format.

Original loopback fixtures cover typed movie/episode previews, malformed feeds,
namespace/size conflicts, bounded item inventories, credential redaction,
changed identities, paused/in-flight source changes, document errors, the legacy
policy contract and protected API/CLI/browser views. This source requires its
own complete Actions run. The optional `format/**` workflow edits source only;
the existing five validation/build/package/publication jobs remain mandatory.
