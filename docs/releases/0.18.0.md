# Coordinated shared-group upgrades

A shared video can now receive a baseline and a replacement for its complete
2–64-owner canonical range. Preview/apply is available through `library-group`,
`POST /api/library/ID/group` and current shared-owner pages in the browser.
Quality uses the current episode profile, complete source range/season identity
and cutoff. Replacement authenticates one new torrent/path and records all jobs
and immutable parent lineage in one synchronized transaction before acquisition.

Each replacement confirms its new exact library path in Plex and enters
`staged`. The original group remains current until the last required owner
confirms; one journal transaction then promotes every owner together. Native
verification, a private shared copy and deterministic range naming retain all
earlier library files and payloads. Staging and promotion survive restart.

Cancellation and retry of a replacement owner now operate on its complete group,
including staged owners. Monitoring changes fence claims/promotion. Failed groups
reserve their complete parent scope until cancelled; retries reject obsolete
parents and competing replacements. Stale workers cannot complete a cancelled
or newly leased operation. Existing independent requests retain their behavior.

Group journal/snapshot format 3 prevents older binaries from silently ignoring
coordinated state. Readers retain compatibility with formats 1 and 2. Browser
reviews keep acquisition credentials server-side, expire after ten minutes and
require the same session/owner/guard. Unknown or partial scopes fail before writes.

The operation is shared-file to shared-file. Splitting into individual files,
automatic range inference/search and deleting earlier imports remain later work.
No full stack parity or unmeasured performance is claimed.

Rust 1.99.0, zero Cargo dependencies, English text and GitHub Actions validation
remain in place. CI runs every Cargo harness in bounded parallel execution,
checks GNU/musl builds, native/container demonstrations and package integrity,
and alone creates the validated tag and seven release assets.

See the [group upgrade guide](https://github.com/alecerf/mynou/blob/v0.18.0/docs/group-upgrades.md)
for operations and recovery and the
[roadmap](https://github.com/alecerf/mynou/blob/v0.18.0/docs/roadmap.md) for later stages.
