# 0.22.36 — private episode-date calendar file

Someone following series can now save known episode dates to their own
calendar. The authenticated Calendar page offers one explicit download of an
iCalendar (`.ics`) file for the current from/to/series filters. It is a portable
file, not a public feed, subscription or third-party integration.

The file holds the complete chosen window only when it has at most 200 known
dated episodes; larger windows show an instruction to narrow the dates or pick a
series instead of exporting a partial page. Episodes without a known date are
excluded. Events are all-day UTC catalog dates with no guessed hour, timezone,
alarm, attachment or URL, and each describes the date as one that may change.
UIDs combine the retained series scope identifier with season and episode, so a
later export keeps the same event identities. Scopes are not deduplicated.

Titles are escaped (backslash, comma, semicolon, newline), redacted by the
existing report rules and limited; lines fold at 75 octets without splitting
UTF-8 characters, and output is bounded to 2 MiB. Malformed or unknown query
fields and invalid dates return English errors.

The route requires the existing browser session, is read-only (no catalog
refresh, search, acquisition, journal or configuration write), and responds as
an attachment with a Mynou-chosen filename, `text/calendar`, `no-store` and
`nosniff`. API cookies gain no API authentication.

Original CI-only synthetic cases cover leap and range-end dates, Unicode folding,
injection-like titles, limits, session, privacy and read-only behavior. No
calendar-client interoperability is claimed without CI evidence. This source
version is proposed until actual CI, distinct Security and complete-diff QA, and
Actions-only immutable publication are complete.
