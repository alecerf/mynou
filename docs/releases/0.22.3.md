# Mynou 0.22.3 — Durable native Usenet staging queue

Opt-in native workers fetch explicitly reviewed NZB files into private checked
workspaces. Exact original NZB bytes are retained once per source; immutable
provider/file/size/attempt bindings prevent implicit reconfiguration. Checked
queue snapshots and saved reservations precede each article request, and verified
receipts are reused after restart. Complete output is reverified before exposure.

At most two active operations share the queue. Per-provider NNTP ownership,
retained attempt budgets, bounded retries and stale-result fences cover pause,
resume, cancel, restart and shutdown. Guarded CLI/API/browser controls expose
redacted progress without subjects, message IDs, paths or credentials. Raw staging
does not create canonical requests or library jobs.

Original local fixtures cover receipt recovery, interrupted reservations,
concurrent slots, control races/replay, provider binding/removal, corruption,
private modes/links/ownership, whole-file integrity, background workers and
service/browser/CLI authentication. This source requires its own complete CI run.
Rust std only, zero dependencies and Actions-only publication remain mandatory.

Library admission and Newznab discovery follow separately. This increment accepts
raw yEnc files only; it does not extract archives or repair PAR2. Incomplete or
corrupt workspace construction is preserved and rejected rather than cleaned up
implicitly. The HTTP API retains its one MiB request-body limit; NZB parser bounds
are larger. Per-file caps do not constitute a global disk-space quota.
