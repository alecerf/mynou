# Mynou 0.22.11 — Native PAR2 format foundation

Adds read-only `par2-inspect` and a bounded original PAR2 core packet reader using
safe Rust std only. Packet checksums, Main/file identities, complete joins,
duplicates, portable names, resource limits and recovery source digests are
checked. Original RFC 1321 compatibility MD5 has published-vector coverage.

This increment inspects one complete core set. It does not repair or verify
protected content, merge volumes, recover damaged packets, support Unicode or
admit PAR2 into library jobs. MD5 never authorizes media operations. See
[format support and hard limits](../par2.md).

Tests are original synthetic fixtures, including hostile packets, cancellation
and read-only CLI boundaries. CI alone validates and publishes this version.
The linked Issue #2 / PR and Actions contain actual source, test, review and
publication evidence. Until those gates succeed, 0.22.11 remains proposed.
Previously published v0.22.10 at `f5c59506d0a8d431d09e9f351e2de2ef71b124f9`
and its seven assets remain immutable.
