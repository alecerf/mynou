# Proposed Mynou 0.22.16 — Native macOS deployment

Add standalone Apple Silicon and Intel executables, built on standard
`macos-26` and `macos-26-intel` GitHub-hosted runners. Each native target must
pass Mach-O architecture inspection and the original local torrent/media/import/
Plex demonstration. Both builds join the objective delivery gates; Linux GNU/
musl, every existing Rust test and Docker behavior remain mandatory.

Packaging consumes checked artifacts from the same workflow and exact source
commit, preserves their bytes and executable modes, and adds individual SHA-256
files and release-manifest entries. Actions alone publishes the immutable release.
The [macOS guide](../macos.md) covers authorized download, verification, installation,
configuration and TLS trust. No Apple Developer signature, notarization or
automatic background-service installation is claimed.

Mynou remains safe Rust standard library only with zero Cargo dependencies.
Registry/release simplification (#18) and execution-control storage (#19) are
separate user requests. Passing CI, complete-diff Security and independent QA
are required before merge. [Issue #17](https://github.com/alecerf/mynou/issues/17)
retains live evidence; this proposed source version does not prove publication.
