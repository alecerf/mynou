# Explicit episode numbering with retained library identities

Mynou now separates retained library numbers, current catalog labels and source
labels. Known catalog episode IDs keep their original canonical numbers when an
explicit decision approves renumbered catalogs, alternate seasons or absolute
source numbers. Existing jobs, exclusions, imports and request keys are preserved.

Use `series-numbering ID`, `POST /api/series/ID/numbering`, or **Episode numbering**
in browser series details. Preview compares the current catalog and proposed
choices without writes or payload acquisition. Apply fetches again and requires
the exact reviewed plan ID; stale, ambiguous or conflicting choices cannot be
saved. Accepted choices and the normalized catalog persist atomically before
future requests capture their source labels.

Individual source queries, title matching and multi-file selection use the saved
explicit source labels while import names and Plex confirmation retain canonical
numbers. Earlier requests without a source choice keep their behavior. Series
snapshot schema 1 is read without migration writes; successful saves use schema
2 with bounded retained identity history. Earlier identities cannot be reused
after catalog disappearance or across conflicting scopes.

This release deliberately validates numbering before shared physical import
ownership. Multi-episode videos, automatic anime-order inference and library
renaming/deletion remain outside 0.16. Automatic season packs with alternate
source labels require explicit file mappings; monitored preference falls back to
ordinary individual jobs. The next release addresses shared multi-episode files.

Rust 1.99.0, zero Cargo dependencies and CI-only validation/publication remain in
place. Actions runs every Rust test through the bounded parallel scheduler,
checks native/static builds and demonstrations, validates Docker/archive/checksum
assets, and alone publishes the release for the validated source commit.

See the [numbering guide](https://github.com/alecerf/mynou/blob/v0.16.0/docs/numbering.md)
for operations, persistence and exact bounds, and the
[roadmap](https://github.com/alecerf/mynou/blob/v0.16.0/docs/roadmap.md) for later stages.
