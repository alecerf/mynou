# Mynou 0.22.21

Container publication accepts the exact verified source repository when it is
public or private. The container package must still be private, with its original
identity, source/version tags, digest, checked executable and isolated runtime
verification. Publication proof records source and package visibility separately.

This corrects the release failure after the source repository became public.
Release download guidance follows repository access settings; private container
packages still require authentication. Earlier immutable releases and images are
preserved.
