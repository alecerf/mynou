# Mynou 0.22.5 — Held native Usenet ownership

Trusted library callers can prepare an exact NZB file under an immutable owner,
source, provider and resource binding. Preparations remain held until the caller
validates current admission and grants at most sixty seconds of authorization.
Permissions live only in memory; reopening never restores acquisition rights.
Workspace descriptors and receipts also bind the owner, preventing implicit
adoption of another owner's checked storage.

Expiry, revocation, restart, active-slot ownership and late-result fences retain
verified receipts and spent article attempts. Explicit retry never resets the
captured budget. Owned file access rechecks both current permission and complete
integrity. Raw queue controls cannot take over owned source files. Public API and
browser views report ownership/progress without private bindings or data.

Owned snapshots use MYNOUU02; old readers reject them rather than ignore an owner.
Raw record identities, workspace bindings and the preceding MYNOUU01 contract
remain intact. Unknown/corrupt constructor data is preserved and rejected.
Original fixtures cover held/idempotent preparation, constructor recovery,
restart/receipt reuse, permission expiry and renewal, active revocation, attempts,
raw/owned conflicts, renamed workspaces, format downgrade, corruption, provider
changes and protected views. This source requires its own complete Actions run.

This increment provides the checked library interface, not automatic canonical
admission. The following Engine increment must validate joint journal/queue
ownership and retain requester approval/quota, captured quality/destinations,
numbering, media/import and Plex gates before using the interface. Newznab search
and document reads remain nonacquiring until that path is connected. Archive
extraction and PAR2 repair remain explicit later stages.
