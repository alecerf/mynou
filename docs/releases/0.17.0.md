# Explicit shared video ownership

One authenticated torrent video can now serve 2–64 consecutive canonical
episodes in one season. Mynou records all owners in one synchronized journal
transaction before acquisition and imports one deterministic Plex range file.
Each logical episode confirms that exact path separately in Plex.

Use `series-shared-file ID --url SOURCE --mapping FILE`,
`POST /api/series/ID/shared-file`, or **One video for multiple episodes** in
browser series details. Preview inspects bounded metadata without acquiring
payload or recording jobs. Apply authenticates again and requires the exact
reviewed plan. Browser review sources stay server-side and expire after ten minutes.

Concurrent group claims are serialized. Interrupted ownership writes recover
all owners or none; restart and retry reuse one verified destination without
overwriting different bytes. Cancellation retains interests required by queued
owners, including before their native transfer ID is recorded. Later subset
requests reuse the full immutable binding and existing terminal states.

Shared journal/snapshot formats reject silent downgrade to earlier readers.
Individual remapping, baselines and upgrades are blocked for shared owners.
Coordinated group replacement is the next release; automatic pack inference
continues to require unique single-episode videos. No video cutting, library
renaming/deletion or full stack parity is claimed.

Rust 1.99.0, zero Cargo dependencies, English project text and CI-only validation
remain in place. GitHub Actions runs every Cargo target through the bounded
parallel scheduler, checks GNU/musl builds and demonstrations, verifies
Docker/archive/checksum assets, and alone tags and publishes the validated commit.

See the [shared-file guide](https://github.com/alecerf/mynou/blob/v0.17.0/docs/shared-files.md)
for operations, persistence and bounds, and the
[roadmap](https://github.com/alecerf/mynou/blob/v0.17.0/docs/roadmap.md) for later stages.
