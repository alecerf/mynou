# Automatic season-pack search and guarded acquisition

Search and rank season packs under the episode profile, inspect authenticated
torrent metadata without payload downloads, and map unique numbered files to
every eligible missing aired episode in the accepted catalog plan. Ordinary
movie and episode matching remains strict. Preview decisions explain rejected
titles and unresolved mappings without exposing acquisition URLs.

Use `series-pack-search ID --season N`, Bearer
`POST /api/series/ID/pack-search`, or **Preview season packs** in browser series
details. Guarded apply binds the reviewed catalog scope, candidate, torrent hash
and exact paths. A changed scope or mutable HTTP torrent cannot silently switch
the acquisition. Jobs persist exact mappings and immutable origin provenance
before workers begin, then share native selective acquisition and verified
imports. Pack provenance does not invent a per-episode upgrade baseline.

Optional `series_packs.enabled: true` makes monitored tracking and refresh try
mapped packs before individual episode jobs. Unresolved packs fall back to
individual acquisition within the same shared deadline and combined 64-job
batch. Earlier configurations default to individual acquisition. On-demand
pack actions also work with background monitoring off and do not enable it.
Existing failed/cancelled requests remain deduplicated rather than retried.

Metadata decisions are bounded to eight ranked candidates, 1,024 files and
1 MiB of path bytes. Magnets use bounded explicit-peer/tracker discovery;
metadata-only tracker queries may be declined and have no DHT/PEX fallback.
Multi-episode videos, general alternate/anime numbering, selection contraction
and partial seeding remain later stages. No public-swarm throughput or personal
installation compatibility is claimed.

This release keeps Rust 1.99.0, the standard library only, zero Cargo dependencies
and CI-only validation/publication. GitHub Actions alone publishes the validated
source ZIP, static Linux x86_64 binary, Docker image archive and checksum files.
See the [automatic pack guide](https://github.com/alecerf/mynou/blob/v0.15.0/docs/automatic-packs.md)
for exact identity rules, bounds and persistence, and the
[roadmap](https://github.com/alecerf/mynou/blob/v0.15.0/docs/roadmap.md) for subsequent
releases.
