# Mynou 0.20.4 — Required NickServ identification

Sources can require one transient IDENTIFY account/password exchange with an
explicit trusted service. Only an exact account-bound NOTICE permits channel
entry. Premature or forged membership grants no authority, configured failures
invalidate the connection, and retries identify again within the existing fixed
registration deadline. SASL and NickServ are mutually exclusive.

Credentials never enter history, reports or diagnostics. Public source/browser
health shows required/identified state and resets on disconnect. Unchanged
unauthenticated/SASL sources retain their bindings; policy changes need a new ID.
Original local fixtures cover trust, configuration/credential bounds, redaction,
reconnect/restart, shutdown, the native CLI and nonrenewable deadlines.
