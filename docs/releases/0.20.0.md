# Mynou 0.20.0 — IRC reception and announcement reviews

Opt-in sources register, join configured channels, answer PING and record strict
release claims from allowed senders. Native TLS verifies the server; bounded
parsing, deadlines and reconnect/backoff keep explicit resource limits. A shared
shutdown monitor interrupts connected sockets.

Named profiles and filters produce per-rule outcomes. A private checked snapshot
preserves canonical/hash identities, original claims and reviewed decisions across
duplicates and restart. CLI/API/browser management exposes source health,
configuration, bounded history and guarded acknowledgement/dismissal.

This independently usable IRC release records reviews without acquisition.
Automatic grabs follow after metadata, canonical identity, requester approval,
quotas and ownership are bound together. Original local fixtures cover protocol
boundaries, trust, filtering, corruption, capacity, reviews, reconnect and shutdown.
