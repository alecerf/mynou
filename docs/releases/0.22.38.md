# 0.22.38 — native Usenet upgrades for owned movies and episodes

Issue 46. `mynou upgrades` (CLI, API and monitoring) can now select a Newznab
candidate for an ordinary monitored single movie or episode with a release baseline.
Preview stays nonacquiring. Apply records at most one pending child that captures the
source, profile and provider binding at creation, then uses the existing guarded
native pipeline: live lease and current requester approval, captured document and
attempt budgets, cancellation, explicit retry, independent versioned import and exact
new-path Plex confirmation. The old import stays current until then.

Shared groups, packs, IRC, ZIP/RAR/PAR2 and implicit provider fallback are excluded;
torrent upgrades are unchanged. Records use the existing `MYNOJ06`/`MYNOS06`
formats; older binaries reject them. CI-only loopback end-to-end fixtures remain
follow-up work. No local validation.
