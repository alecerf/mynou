# Selection profiles and search previews

Automatic movie and episode acquisition can now use separate named selection
profiles. Configure allowed resolutions, sources, codecs and audio-language
markers in preference order, reject unwanted title phrases, require specific
phrases, and apply custom scoring rules.

`mynou search` and authenticated `POST /api/search` explain candidate selection
without adding a job or starting a download. Reports include parsed attributes,
ranking and rejection reasons, but exclude acquisition URLs and credentials.
Authenticated `GET /api/profiles` exposes the active profile configuration.

Existing configurations without a selection section retain unrestricted,
seed-count-based selection. Generated configurations start with the same `any`
profile. See the [selection guide](https://github.com/alecerf/mynou/blob/v0.7.0/docs/selection.md) for configuration,
ranking order, unknown markers and safe preview examples.

Language and quality markers describe release titles; they do not prove the
contents of downloaded audio/video tracks. Automatic upgrades and library
monitoring remain future milestones.
