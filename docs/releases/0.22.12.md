# Mynou 0.22.12 — Bounded native single-file PAR2 recovery

Adds original safe Rust std-only GF(2^16) arithmetic and
`par2::Set::recover_single`, with a cancellable variant. The library identifies
damaged or missing slices and reconstructs one described recoverable file into
caller-owned memory. No file writes, overwrites or library admission are added.

The supported subset is a complete core set in one captured source, at most
256 protected slices, eight erasures, 16 MiB of content and 1 MiB per slice.
Missing slices require consecutive parity exponents starting at zero.
`RecoveryLimits` bounds additional buffers to 32 MiB and field work to
134,217,728 operations; applications may lower these limits. Source/header/payload
identity, zero-padded slice MD5/CRC32, whole-file MD5 and first-16-KiB MD5 must
match before output is returned. Checksums provide compatibility, not authenticity
or media authorization. Partial failed/cancelled buffers are discarded.

Inspection remains read-only and reports `content_verified: false` and
`repair_supported: false`; it does not invoke recovery. Multi-file recovery,
volume merging, recovery paths/ownership, damaged-packet resynchronization,
Unicode and Usenet library admission remain separate work. See [support](../par2.md).

Original synthetic CI fixtures cover published constants, an independent
polynomial oracle, multiple/maximum erasures, chunk boundaries and zero padding,
truncation/missing/empty input, wrong or insufficient parity, source mutations,
cancellation, resource limits, unchanged input and final file integrity.

This release is proposed until actual final CI, separate Security/QA reviews,
merge and immutable Actions publication succeed. [Issue #6](https://github.com/alecerf/mynou/issues/6)
and [PR #8](https://github.com/alecerf/mynou/pull/8) retain exact source, review,
timing and publication evidence. CI alone tags and publishes; previous releases
and assets remain immutable.
