# Mynou 0.21.1 — Checked source policy and reviewed controls

Source pause/enable policy now persists in a private checked snapshot and is
applied before workers. Optional stable source IDs have immutable bindings;
removed sources retain policy. Cookies and credential values remain ephemeral.
Protected CLI/API/browser controls review whole-policy guards before pause,
enable, session reset or a bounded source probe. Changed policy invalidates
active responses. Browser reviews bind session/source/action and expire.

Preview is read-only and performs no source request. Applied probes record their
revision before transport, respect authentication/rate limits and never queue
media. Corrupt, linked, public or unsupported policy snapshots fail closed.
Original local scenarios require this source's own complete Actions validation.
Rust std only, zero dependencies and CI-only publication remain mandatory.
