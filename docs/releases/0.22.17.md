# Mynou 0.22.17 — private registry images and simpler releases

Proposed source scope for user Issue #18. Publication is established only by
the exact default-branch Actions run, private GHCR digest and immutable release.

- Publish the checked Linux amd64 scratch image to private `ghcr.io/alecerf/mynou`
  with source/version identity and a content-addressed digest in release notes.
- Keep only the Linux x86_64, Apple Silicon and Intel executables plus one checksum
  manifest as release assets. Retire custom source ZIP/image archive publication
  and the original unused ZIP packager. GitHub native source downloads remain.
- Generate Compose with the executable's version and an optional `MYNOU_IMAGE`
  digest override. Document private-package authentication and safe upgrades.
- Default-only ephemeral package permission, collision/visibility refusal,
  idempotent interrupted publication, re-pulled bytes and isolated demo verification.
  Registry tags are mutable by platform; digest pins are the durable guarantee.
- Preserve Linux/native macOS validation, runtime demonstrations, byte checks,
  independent Security/QA gates and all previous immutable releases.

Rust remains safe std only with zero Cargo dependencies and no runtime helpers.
No Linux arm64 image, public package, new credential, paid service or product
feature is implied. Ten original publication regression scenarios run only in CI;
actual default publication must still verify package permissions and availability.
