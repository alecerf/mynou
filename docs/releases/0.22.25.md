# Mynou 0.22.25

Install recoverable branch-independent engineering control administration.
The fixed legacy fence rejects old workers, notes retains complete control/review
history, and interrupted cutover uses native recovery and renewable role leases.
The sole fenced owner can checkpoint, renew and deliberately release; the next
worker verifies its native parent and preserved work before resuming, without
waiting for an intentionally released lease to expire.

Continuous useful execution and the existing hourly recovery schedule remain.
Strict trusted-default commands gate activation and eventual branch retirement.
Installation does not claim actual notes activation or task reconciliation.
Issue19 stays In Progress until live notes transport, the actual hourly-task
response, legacy retirement and fresh admission are verified on GitHub.

Product Rust remains safe std with zero Cargo dependencies. Source is public;
the existing container package remains private. Actions alone checks, tags and
publishes immutable artifacts. Published v0.22.24 remains unchanged. No local
verification, paid worker or guaranteed infinite execution is introduced.
