# Mynou 0.22.0 — Original NZB and yEnc integrity primitives

Native Usenet support begins with bounded NZB inventories and read-only local
inspection. The original XML parser is shared with existing RSS/Torznab; external
entities and DTDs remain rejected. Article identities, numbering, counts and
sizes are explicit and bounded. Public inspection omits private provider claims.

Original binary yEnc decoding returns parts only after CRC verification. Complete
assembly requires consistent identities, exactly numbered parts, contiguous
coverage and a matching whole-file CRC. Missing parts, overlaps, gaps, corruption
and unsafe filenames fail. The initial in-memory assembly is limited to 64 MiB;
CRC detects accidental corruption, not semantic media identity.

Original synthetic format fixtures require this source's complete Actions run.
Rust std only, zero dependencies and CI-only publication remain mandatory.
Native NNTP/TLS, disk-backed acquisition/recovery and Newznab follow in separate
0.22 increments. Archive extraction and PAR2 repair are not implemented here.
