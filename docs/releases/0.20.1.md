# Mynou 0.20.1 — Approved IRC candidate routing

An explicit grab rule holds compatible admitted jobs for IRC selection.
Configured hash-pinned magnets authenticate metadata before routing a matching
claim to one existing canonical job. No announcement creates unsolicited demand.
Title/year/source labels, captured profile, requester approval/quotas and
exclusive physical ownership must agree.
Plex availability remains active for held jobs, and routing checks the captured
destination before choosing a torrent. Existing media fulfills demand without
acquisition; verified candidates wake deferred jobs for immediate processing.

Durable reservations precede immutable journal origins. Recovery completes
committed bindings and aborts uncommitted intents without replay. Retry retains
the chosen magnet, hash aliases, exact file and release baseline. Native imports
use that verified file; ordinary jobs and audit reviews keep their behavior.

CLI/API/browser reports expose routing outcomes and associated jobs without
private magnets, templates or credentials. Original loopback/native fixtures
cover the full path, metadata-only ordering, approval/removal races, ambiguity,
source numbering, duplicates, restart, corruption and format downgrade.
