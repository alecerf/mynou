# 0.22.31 — native browser form compatibility

Native browser forms may omit Origin. Mynou previously rejected them before
checking the sign-in cookie, CSRF token or API key, while its no-referrer policy
also removed the browser's referring address. This proposed fix accepts a
strictly validated same-origin Referer only when Origin is absent.

A present Origin remains authoritative: empty, null, malformed or foreign values
are rejected even with a valid Referer. Same-origin referrer policy retains the
fallback inside Mynou without sending private addresses or paths cross-origin.
Session/challenge rotation, CSRF, token checks, cookie attributes, HTTPS-origin
binding, cross-site metadata rejection and API/browser separation remain required.

Original CI-only native HTTP/state/privacy scenarios cover login, actions and
logout without Origin, hostile headers, token/CSRF failures, default ports, host
case, IPv6 and HTTPS scheme/port isolation. Protocol fixtures are not an actual
Safari engine run or a claim about every personal browser installation.

This source version is proposed. Distinct exact-head/base Security/full-diff QA,
all objective gates and Actions-only immutable publication remain required.
No JavaScript, Cargo dependency, unsafe/FFI or external runtime helper is added.
