# Proposed Mynou 0.22.14 — Read-only PAR2 protected-content diagnosis

Add `par2-verify FILE --root DIRECTORY` and exact-ID library verification reports
for up to eight recoverable files, 16 MiB combined content, 256 slices and 1 MiB
slices. Reports include lengths, presence, local/global damaged indices and
slice/full-file/first-16-KiB integrity. Whole-file disagreement cannot hide behind
matching slices. Empty files and missing/truncated content are explicit. Clean
CLI verification exits zero; damage prints JSON and exits nonzero.

The offline directory adapter opens only captured portable names under an
explicit existing root. Link/type/opened identity and path fences, source binding,
protected-byte rereads and cooperative bounded cancellation protect observations.
No configuration or directories/files/journals are created. This is not a general
atomic filesystem snapshot, parity verification, reconstruction, authenticity or
ownership/library authority. Persistent repair/admission remains subsequent work.

Original CI fixtures cover global order/damage, empty/nonrecoverable metadata,
whole-file disagreement, identity/aggregate bounds, cancellation/source changes,
missing/type/link paths, clean/corrupt CLI behavior and unchanged source/storage.
The prior 846-test baseline and objective gates remain required. No local checks
run. Separate complete-diff Security and logically independent QA under scoped
exact-head/base leases precede merge. Actions alone publishes immutable assets.

This source version is proposed until actual validated default CI publication.
[Issue #13](https://github.com/alecerf/mynou/issues/13) retains live evidence.
