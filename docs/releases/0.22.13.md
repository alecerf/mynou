# Proposed Mynou 0.22.13 — Bounded native multi-file PAR2 memory recovery

Adds original safe Rust std-only `Set::recover_files` and its cancellable variant.
Explicit `RecoveryInput` values bind immutable bytes to every captured recoverable
File ID, in any caller order. One global Main/file/slice map assigns coefficients
across file boundaries. `RecoveredFile` outputs follow Main order and are returned
only after every slice and file is verified. The existing single-file API shares
the reconstruction engine and preserves its supported behavior.

`MultiRecoveryLimits` may tighten eight recoverable files and the aggregate bounds:
16 MiB content, 256 slices, eight erasures, 1 MiB slices, 32 MiB additional memory
and 134217728 field operations. Missing data requires consecutive parity exponents
starting at zero. Source/header/payload identity, slice padding/MD5/CRC, whole-file
and first-16-KiB MD5, cancellation and discarded partial output remain mandatory.
Unknown, duplicate, nonrecoverable, omitted and oversized input bindings fail.

Original independent parity fixtures cover global coefficients, caller reordering,
cross-file and maximum erasures, empty/missing/truncated files, nonrecoverable
metadata, aggregate limits, corrupt/insufficient parity, large padded chunks,
source changes, cancellation and rejection of a later file after earlier success.
All previous tests and objective gates remain required; checks run only in Actions.

File IDs and checksums do not authorize filesystem writes or ownership/library
admission. No repair paths, overwrites, journals, volume merging, acquisition
permission or external runtime helpers are added. Inspection remains read-only.

This release is proposed until final CI, complete-diff separately leased Security
and logically independent QA, merge and immutable Actions publication succeed.
[Issue #9](https://github.com/alecerf/mynou/issues/9) and
[PR #10](https://github.com/alecerf/mynou/pull/10) retain actual evidence.
CI alone tags and publishes; previous released tags and assets remain immutable.
