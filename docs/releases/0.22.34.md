# 0.22.34 — faster CI with fewer GitHub API requests

This version carries no product code change since 0.22.33. It reduces CI latency,
noise and GitHub API use, and removes failure modes that blocked delivery.

**Actions-log audit.** On 2026-10-09 audit full sweeps (1,381 and 1,532 requests
per run) exhausted the repository's hourly token quota, so other workflows failed
with HTTP 403. Audits also failed when a run was created while they paginated the
run list, and a full sweep could no longer fit its request bound beyond about 2,450
attempts. The audit now:

- tolerates runs repeated by shifting pages;
- binds receipts to the literal detection `RULES` and an explicit `SCANNER_VERSION`
  instead of the scanner's file bytes, so refactors keep coverage;
- re-lists only recent runs on routine audits and every run within GitHub's 30-day
  rerun window on a deep audit at least every 20 hours, instead of all history;
- downloads at most 1,000 uncovered archives per run, newest first, recording a
  `partial` receipt that the next audit continues;
- skips log downloads for skipped runs and records retention-deleted logs;
- rebuilds coverage when its receipt expired instead of failing forever.

It runs hourly, on default-branch pushes and on dispatch. It no longer gates pull
requests: log coverage is repository-wide history, and a PR's own CI is still
running when its audit starts. Source-history scanning still gates every PR.

**QA gate.** `agent-qa-review` no longer runs on pushed heads, which never carry
their own review records, so a push no longer waits ten minutes and fails. On a
review event it waits only while required CI runs, with one run listing per poll,
and fails at once for missing or rejected reviews, closed PRs or completed red CI.

**Delivery and commands.** Delivery wakes only on a passed `Engineering checks`
PR run, a default-branch `Mynou CI` result, trusted handoffs, the schedule or a
dispatch. Concurrency moved to the job level, so comment runs that are skipped can
no longer cancel a queued control command, as happened twice on 2026-10-08.
Engineering processes reuse commit-addressed reads (commits, comparisons, content
at a commit) instead of re-fetching them on every state read.

**Build matrix.** The Intel macOS executable is cross-compiled on Apple Silicon
and demonstrated under Rosetta 2; the Intel build was the critical path of every
source-changing PR. The unpublished GNU release build is removed: validation
already builds, lints and tests that target. A newer PR head cancels its older
run, delivery-dispatched default CI saves caches, and pull requests no longer
compress an image that only default-branch publication uses.
