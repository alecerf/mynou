# Selective native acquisition for mapped packs

New mapped pack transfers acquire the retained union of exact torrent file
paths and their required pieces. Verified mapped episodes can import while the
rest of the torrent remains incomplete. `selected_ready` and per-file
verification are separate from whole-torrent `ready`; a partial transfer never
advertises complete pieces, seeds payload or announces tracker completion.

v1 selection verifies complete boundary pieces and retains their neighboring
bytes in confined files. v2 requires selected file roots and authenticated
proofs/layers; hybrid selection also verifies v1 hashes. Restart rehashes bytes
before making paths available. Selection expansion retires prior peer workers
under the same verified-write generation guard.

Use `torrent-select ID --selection '{"indices":[0,2]}'`,
`POST /api/transfers/ID/selection`, or **Include file** / **Download all files**
in browser transfer details. Shared interests only expand, retaining pause,
priorities, rates, counters and source/library files. Existing full acquisitions
keep that policy. Cancellation retains interests and cannot discard another
request's required pieces. An explicit correction can replace a missing path
proven absent by authenticated metadata while retaining every real interest.

The selection is durable before queue publication, bounded to 1,024 paths and
1 MiB of path bytes, and protected by existing strict API/form authentication.
Do not downgrade 0.14 native storage to older control readers. Earlier records
without a selection retain full acquisition.

This focused release preserves Rust standard library only, zero Cargo
dependencies and CI-only validation/publication. Automatic season-pack search,
numbering rules, multi-episode files, selection contraction and partial seeding
remain later stages. No general throughput or installation-compatibility result
is claimed.

See the [transfer guide](https://github.com/alecerf/mynou/blob/v0.14.0/docs/transfers.md)
for exact behavior and bounds, and the
[roadmap](https://github.com/alecerf/mynou/blob/v0.14.0/docs/roadmap.md) for following
releases. GitHub Actions alone publishes the validated source ZIP, static Linux
x86_64 binary, Docker image archive and checksum files.
