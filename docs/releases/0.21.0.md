# Mynou 0.21.0 — Native indexer authentication and session health

Original JSON/RSS/Torznab search now supports Basic/Bearer credentials and an
explicit same-origin single-cookie form adapter. Sessions stay in memory, obey
bounded scope/expiry checks and renew at most once after 401. There is no
unauthenticated fallback or redirect. Source intervals and bounded 429 cooldowns
limit new requests; concurrent same-source work reports busy. Protected API,
browser and CLI health omit endpoints, credentials and raw response bodies.

Original local source fixtures cover credentials, session sharing/renewal,
expiry, malformed cookies, adapter parsing, redirects, rate/disabled sources,
independent providers, concurrency and protected views. This source requires its
own exact complete Actions run/publication. GitHub Actions alone creates release
artifacts. Rust std only and zero Cargo dependencies remain mandatory.

Checked persistent source policy controls follow in 0.21.1. Interactive/CSRF/
CAPTCHA login, arbitrary cookie jars and broad provider compatibility remain
outside this explicit adapter contract. Native Usenet and verified cross-seeding
continue afterward.
