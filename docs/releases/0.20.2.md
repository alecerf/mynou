# Mynou 0.20.2 — Required IRC authentication

Optional SASL PLAIN authenticates a configured IRC source before channel
membership or announcement delivery. Bounded capability negotiation requires
server support, ordered acknowledgement/challenge/success and a correctly
addressed result. Rejection, unsupported commands, logout or deadline expiry
close the connection without unauthenticated fallback. Every reconnect performs
the handshake again.

Environment variable names configure bounded UTF-8 credentials. Values and
encoded responses stay transient and absent from errors/public reports/history.
Original Base64 encoding handles 400-byte chunks and exact-boundary terminators.
Old configurations keep their source binding; authentication policy changes
require a new stable source ID. Remote use retains certificate-verified TLS.
Public source reports and the browser expose required/authenticated state.

Original local fixtures cover strict configuration, fragmented/bounded
capabilities, protocol failures, redaction, reconnect/restart, missing credentials,
native CLI chunk boundaries, shutdown and the ten-second registration deadline.
Only PLAIN is supported; values are sent without SASLprep/Unicode normalization.
NickServ, tracker text adapters and broader actions remain later stages.
