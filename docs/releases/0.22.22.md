Mynou v0.22.22 adds an authenticated GitHub-comment transport for bounded engineering control commands. Reviewed default Actions perform exact-head lease updates with the existing single-parent, non-force protocol; scheduled workers can recover through native GitHub without relying on a local workspace. An inert notes-reference probe supports proving the replacement transport before a separate live control-storage cutover.

Product runtime remains English, safe Rust standard library only with zero Cargo dependencies. Release assets remain immutable and CI-owned. Live task scheduling and the canonical control location do not change in this release.
