# Mynou 0.20.7 — Durable native notification delivery

Requester and IRC outcomes now enqueue fixed route-bound events in the same
checked snapshot as their decisions. Opt-in native HTTP delivery retains stable
IDs, immutable endpoint bindings, bounded attempts, saved leases and restart
recovery. Redirects are rejected, preferences remain effective, and public
CLI/API/browser reports expose aliases/status rather than endpoints or secrets.

Delivery is at-least-once; receivers must deduplicate the event ID. Retry and
discard use guarded scope without resetting attempts or changing acquisition.
Pending work cannot be evicted at capacity. Adding a route never backfills old
outcomes; removal/disable pauses it. New semantic formats reject old binaries.

Original local fixtures cover protocol, preference, persistence, capacity,
credential isolation, protected controls and background delivery. This source
requires its own complete Actions run; GitHub Actions alone publishes releases.
Rust std only and zero Cargo dependencies remain mandatory. Native indexer
authentication/session/configuration is the next roadmap scope.
