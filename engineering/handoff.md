# Concise native handoff

Put this in the owning Issue or PR, with no secrets or chain of thought:

```text
Role and outcome:
Issue / branch / exact remote commit / PR:
Important decision:
Actual CI/review evidence (or pending):
Unresolved concern:
Next role and useful action:
Control checkpoint SHA / lease released or expiry:
```

Commit before handoff. Push useful partial progress when interruption is possible.
Do not depend on one VM, uncommitted changes or conversation history. Capacity
loss means paused, never Done/Failed. For rejected QA, reference the actual finding
and keep the PR unmerged until correction is reviewed. Keep handoffs short.
