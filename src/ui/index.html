            Connect to Mynou

            Paste your access token. It stays in this tab only and is sent as a WebSocket subprotocol, never in a URL. Lost it? Stop Mynou and run mynou token --reset.

            Welcome to Mynou

            Create the access token that protects this interface and the API.

            Keep this token safe, for example in your password manager. Mynou keeps only a fingerprint of it and can never show it again.

            The command line reads it from the MYNOU_API_TOKEN environment variable. If you lose it, stop Mynou and run mynou token --reset.
